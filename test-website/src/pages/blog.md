# 📝 Welcome to the Blog

This is a **markdown page** in BertUI! You can write content in plain markdown and it will be automatically converted to a React component.

## Features

- Write in simple markdown
- Import React components inside your MD files
- Full support for code blocks, tables, and more

## Code Example

```javascript
function hello() {
  console.log("Hello from markdown!");
}
```

## Why Markdown?

Markdown is perfect for:
- Blog posts
- Documentation
- Simple content pages
